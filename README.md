# Sales Data Analysis System

This project is a Python-based command-line tool designed for interactive sales data analysis, visualization, and reporting.

## Features
- **Load Dataset**: Read CSV files seamlessly.
- **Explore Data**: Summary statistics, shape, and null-value checking.
- **Handle Missing Data**: Options to drop or impute missing values.
- **Data Visualization**: Generate Line Plots, Bar Charts, Scatter Plots, and Histograms.
- **Export Plots**: Save generated charts directly to disk.

## Requirements
- Python 3.x
- `pandas`
- `matplotlib`
- `seaborn`
- `numpy`
